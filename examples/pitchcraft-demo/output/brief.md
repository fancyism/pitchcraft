# Communication brief — demo deck

- **Audience:** marketing teams and AI-agent builders evaluating how to produce decks with agents
- **Knowledge level:** has seen AI-generated decks; has not seen a deck pipeline with a validated DSL
- **Objective:** position PitchCraft as the engine that replaces bullet-dump AI decks
- **Desired action:** install the skill and point an agent at a workspace
- **Tone:** expert but accessible; premium editorial consulting
- **Slides:** 12 — 16:9 — language: en
- **Narrative spine (pitch):** Problem -> Insight -> Solution -> Product -> Proof -> Ask
- **Emotional arc:** recognition ("we've all seen these decks") -> concern -> confidence -> proof -> invitation
- **Style:** default editorial theme (warm paper #FAF7F2, deep green-ink #254741, burnt-orange accent #C46A2F); no custom fonts (portability); no generated images — typography + information design only, proving the "information design beats decorative images" principle on itself
- **Outputs:** html + pptx + json (+ qa-report, sources-map)
